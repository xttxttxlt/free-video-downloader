# 方案设计

> 项目：闪存视频 FlashSave
> 对应实现：`app/`（后端）、`static/`（前端）

## 1. 技术架构

```
浏览器（手机 / 电脑）
   │  贴链接 → 解析 → 选清晰度 → 下载 → 取回文件
   ▼
FastAPI 单进程（app/main.py，无数据库）
   ├── 静态托管 static/（html=True）
   ├── /api/*  业务接口
   ├── 内存状态：tasks / quota / stats
   └── 清理线程：每 300s 删除超过 TTL(1h) 的文件与任务
   ▼
下载引擎路由（app/downloader.py）
   ├── 抖音域名 ──► app/douyin.py 专用模块（requests + 游客 ttwid + ffmpeg）
   └── 其他平台 ──► yt-dlp CLI 子进程（tools/yt-dlp.exe）+ tools/ffmpeg
   ▼
downloads/ 临时文件（task_id.ext，1h 自动清理）
```

选型理由：
- **FastAPI**：代码量最少，一个进程同时提供页面与接口；本机已有 Python
- **封装 yt-dlp CLI 而非改源码 / 用 Python API**：官方 README 明确建议外部程序用 `-J`/`--print`/`--progress-template` 等稳定接口，不要解析易变 stdout；CLI 封装零改动、升级无忧
- **Windows 用独立 yt-dlp.exe**：自带 Python，绕开最新版对 Python 3.11+ 的要求
- **无数据库**：任务/额度/统计内存化，文件落临时目录定时清理，满足轻量诉求

## 2. API 设计

基础路径 `/api`，JSON 交互；错误统一 `{"detail": "友好中文提示"}`。

| 方法 | 路径 | 请求 | 响应 | 说明 |
|---|---|---|---|---|
| POST | `/api/parse` | `{url}` | video 或 playlist（见下） | 解析；400 链接/解析错误 |
| POST | `/api/download` | `{url, choice="best", title?, subtitle?}` | `{task_id}` | 建下载任务；429 额度用完；400 参数错 |
| GET | `/api/tasks/{id}` | — | `{id,status,percent,speed,title,error}` | 轮询进度；status∈queued/downloading/done/error |
| GET | `/api/files/{id}` | — | 文件流（attachment） | 取回成品；文件名=标题+扩展名；404 过期 |
| GET | `/api/quota` | — | `{remaining,limit}` | 当前 IP 今日剩余免费次数 |
| GET | `/api/stats` | — | `{downloads}` | 今日全站下载数（信任条展示） |

`/api/parse` 返回结构：
- 单视频：`{type:"video", engine?, video_id?, title, thumbnail, duration, uploader, webpage_url, choices:[{id,label,height,approx_size?}], subtitles:[lang]}`
  - `choices.id`：分辨率数字（如 `"1080"`）、`"audio"`、`"best"`
- 合集：`{type:"playlist", title, entries:[{title,url,duration}], total, truncated}`（entries 截断前 50）

`/api/download` 的 `choice` 与引擎映射：
- 抖音：仅接受 `best`（无水印 MP4）/ `audio`（MP3），其余归一为 `best`
- 其他：`audio`→抽流 MP3；`best`→最佳；数字→限高清晰度

## 3. 下载策略

### 3.1 路由
`downloader.parse/start_download` 先判 `douyin.is_douyin(url)`（含 douyin.com / iesdouyin.com）→ 走抖音模块；否则走 yt-dlp。

### 3.2 通用平台（yt-dlp）
- 解析：`-J --flat-playlist --no-warnings -- <url>`；playlist 取 entries 前 50，空合集报错
- 清晰度选择子（`_selector`）：
  - `audio` → `ba/b` + `-x --audio-format mp3`
  - `best` → `bv*+ba/b`
  - 数字 h → `bv*[height<=h]+ba/b[height<=h]/b`
- 兼容与封装：`-S vcodec:h264`（优先 H.264）、`--merge-output-format mp4`
- 进度：`--progress-template "download:@PROG@%(progress.downloaded_bytes)s,%(progress.total_bytes)s,%(progress.total_bytes_estimate)s,%(progress.speed)s"` + `--newline`
  - **关键坑**：`--print` 隐含 quiet 会吞掉进度输出，必须加 `--no-quiet`
- 成品路径：`--print after_move:filepath`；只认以 `downloads/` 开头的行作为路径
- 保护：`--max-filesize`（默认 500M）、`--windows-filenames`、`--trim-filenames 80`、`--no-playlist`
- 字幕：`subtitle` 经正则校验后 `--write-subs --sub-langs`

### 3.3 抖音（专用免登录模块）
1. **游客身份**：POST `ttwid.bytedance.com/ttwid/union/register/` 取 `ttwid`（缓存 6h），注入 `.douyin.com/.iesdouyin.com/.snssdk.com` 三个域——纯服务端生成，不碰用户登录态
2. **取 video_id**：短链先跟随重定向；从 `modal_id/item_ids/group_id/aweme_id` 或 `/video/ /note/` 路径正则提取
3. **取元数据**：GET `https://www.iesdouyin.com/share/video/{id}/`（移动 UA）；遇 WAF 挑战页用 SHA256 工作量证明求解 cookie 后重试； brace-matching 解析 `window._ROUTER_DATA` → `loaderData.*.videoInfoRes.item_list[0]`
   - 注：旧 `web/api/v2/aweme/iteminfo/` 主接口已失效（返回 0 字节），故直接走分享页
4. **无水印地址**：`video.play_addr.url_list[0].replace("playwm","play")`，流式下载为 MP4
5. **仅音频**：分享页 `music.play_url` 为空，故先下无水印视频再 `ffmpeg -vn -acodec libmp3lame -q:a 2` 抽 MP3，删中间视频
6. 进度：按 Content-Length 计算百分比（音频模式视频段 0–90%、转换 95%、完成 100%）

来源与许可：adapted from [rathodpratham-dev/douyin_video_downloader](https://github.com/rathodpratham-dev/douyin_video_downloader)（MIT），增强游客 ttwid 与 ffmpeg 抽音频。

### 3.4 并发 / 配额 / 清理
- 并发：`threading.Semaphore(3)`，超出排队（status=queued）
- 配额：`quota[ip]={date,count}`，跨天重置；`FREE_DAILY_LIMIT` 默认 5；下载发起即计数
- 清理：守护线程每 300s 删 `created` 超 1h 的任务及其文件，并扫目录删超龄文件
- 统计：`stats={date,downloads}` 供信任条

### 3.5 安全边界
- URL：`urlparse` 协议白名单 http/https + 必须有 netloc
- 子进程：列表参数、不用 shell；URL 前置 `--` 防选项注入
- 参数：`choice` 数字正则 / 抖音枚举；`subtitle` 正则 `[\w-]{1,20}`
- 前端：标题等一律 `esc()` 转义防 XSS；封面 `referrerpolicy="no-referrer"`
- 文件取回：仅允许 done 任务的 filepath，文件名过滤非法字符

## 6. 二期：AI 视频总结（已实现）

### 6.1 架构

```
浏览器 ── POST /api/summarize {url} ──▶ summarizer.start_summary
   │                                      │ 独立 summaries dict + Semaphore(2) + daemon Thread
   │  GET /api/summary/{id} 1s 轮询        ▼
   │                          queued → fetching_subtitle → summarizing → done | error
   │                                      │
   │                   B站：view API → dm/view API → 直下字幕 JSON（全程免登录）
   │                   其他：yt-dlp -J --no-playlist → 字幕 URL 直下（失败兜底 --write-subs CLI）
   │                                      ▼
   │                          cues[{start,end,text}] → 带时间戳文本 → DeepSeek JSON 总结
   └── POST /api/summary/{id}/chat ──▶ 字幕全文 system + 最近10条历史 → DeepSeek 回答
```

- 与下载完全解耦：独立内存 dict、独立并发 semaphore(2)、独立 cleanup_loop（TTL 1h）；`downloader.py`/`douyin.py` 零改动。
- 配置：根目录 `.env`（gitignore 排除，`.env.example` 入库），启动时极简加载器读入，不覆盖已有环境变量。`DEEPSEEK_API_KEY` 必填；`DEEPSEEK_MODEL` 默认 `deepseek-chat`、`DEEPSEEK_BASE_URL` 默认官方地址，均可改。

### 6.2 字幕管线（关键实测结论）

- **B站字幕接口对游客隐藏的是 `player/v2`，而弹幕接口 `x/v2/dm/view?aid&oid=cid&type=1` 免登录返回字幕列表**（含 `ai-zh` 等 AI 字幕与多语言）。参考 liyupi/free-video-downloader 的实现思路。
- 流程：`x/web-interface/view`（bvid/aid → aid/cid/pages）→ `dm/view` 取字幕列表 → 语言优先级 zh-CN/zh-Hans/ai-zh/zh… → 直下 `subtitle_url`（BCC JSON `body[{from,to,content}]`）。
- 多 P：view 的 `pages` 数组按 URL `?p=N` 取对应 cid（view 的 p 参数不生效）；标题拼接分 P 名。
- 其他平台：yt-dlp 完整 `-J --no-playlist`，`pick_subtitle` 排除 danmaku/live_chat，人工中文 > AI 中文 > 英文 > 其他；格式 srt>vtt>json3>json；直下失败兜底 `--skip-download --write-subs/--write-auto-subs --convert-subs srt`，临时文件读完即删。
- 抖音无字幕：入口即 400「抖音视频暂无字幕，暂不支持 AI 总结」。无字幕视频统一友好提示。

### 6.3 DeepSeek 集成

- `requests` 直调 OpenAI 兼容 `/chat/completions`（不引 SDK）；`thinking={"type":"disabled"}` 关思考提速省钱；总结用 `response_format=json_object`。
- 提示词强制纯文本 JSON：`{summary, chapters[{timestamp,title,points[]}], highlights[]}`；timestamp 必须取自真实字幕；`validate_summary` 校验+裁剪（章节≤8、要点≤6）。
- 已知坑：JSON 解析失败时官方可能返回纯空格 content → 检测空内容重试 1 次。
- 长视频：1M 上下文不做 map-reduce；超 150k 字符等距抽稀（保首尾），结果带 `partial` 前端提示。
- 问答：**SSE 流式打字机**。`stream_chat` 生成器以 `stream=True` 调 DeepSeek，逐 delta yield `data: {"delta":…}`，结束 yield `{"done":true,"rounds_left":N}`，异常 yield `{"error":…}`；system 塞同一份字幕文本 + 最近 10 条历史；每任务 20 轮上限；问题 1~500 字（校验在流开始前，仍走 400）。前端 fetch + ReadableStream 解析 SSE 逐字追加（textContent 累加，天然防 XSS）。实测首 token 0.6s。
- 错误全中文映射：缺 Key 503、401/402/429/超时/JSON 坏 → 友好提示；usage token 数打日志观测成本（实测 40 分钟课程单次总结约 8s、几分钱）。

### 6.4 API

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/summarize` | `{url}` → `{summary_id}`；400 链接错/抖音/无字幕入口校验；503 缺 Key |
| GET | `/api/summary/{id}` | 轮询；仅 done 附带 result/cues/webpage_url/rounds_left（白名单 `public_view`）；404 过期 |
| POST | `/api/summary/{id}/chat` | `{question}` → **SSE 流**（delta/done/error 事件）；404 未完成/过期；400 问题非法/轮数用完 |

### 6.5 前端

- 入口：单视频卡「✨ AI 总结」按钮；合集卡每 P 一个「✨ 总结」小按钮；抖音卡不显示。总结面板占卡片整行宽度（flex-basis:100%）。
- tab 栏参考竞品：图标 + 文字 + 激活蓝色下划线（📝总结摘要 / 📄字幕文本 / 🧠思维导图 / 💬AI 问答）。
- 摘要：段落 + 章节时间戳胶囊（链接 `?t=秒` 跳原视频）+ 亮点块。
- **思维导图：零依赖自绘 SVG 横向树**（参考竞品形态）：根左、章节中、要点右；canvas measureText 测算列宽；贝塞尔曲线连接、每分支一色、节点下划线 + 分支圆点；要点两行换行、根/章节标题截断；激活 tab 时垂直居中到根节点；超宽容器横向滑动 + 提示文案。
- **导出**：思维导图 PNG（SVG 序列化→canvas 2x 白底）与 Markdown 大纲；字幕 SRT 与 TXT；全部前端 Blob 下载，零后端改动。
- 字幕：details 折叠全量 cues + 导出按钮。问答：气泡 + 输入框 + 剩余轮数，SSE 打字机。
- 不引 Markdown 渲染器/CDN：提示词强制纯文本+结构化数组，按语义渲染；**AI 输出同样视为不可信输入，一律 `esc()`**（已用含 `<script>` 的字幕实测转义）。
- auto 字幕提示「基于平台 AI 字幕，可能有识别误差」；partial 提示截断；768/480 移动端无横向溢出（导图容器内部滑动）。

### 6.6 风险与限制

- B站字幕依赖 `dm/view` 免登录口径，平台若收紧需跟进（届时评估站长 cookies 或云端 ASR 兜底）。
- 字幕 URL 带时效 auth_key：解析后立即下载；失败有 CLI 兜底（仅通用平台）。
- 本机 DNS 偶发解析失败 → 统一「网络开小差了」友好提示，重试即可。
- 开发期总结不限额（下载配额不变）；上线前需补总结额度/会员 gating。
- 隐私：仅字幕文本上云（DeepSeek），不上传视频；内存态 1h 清除；FAQ 已明示。
