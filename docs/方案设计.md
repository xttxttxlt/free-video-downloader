# 方案设计

> 项目：闪存视频 FlashSave
> 对应实现：`app/`（后端）、`static/`（前端）

## 1. 技术架构

```
浏览器（手机 / 电脑）
   │  贴链接 → 解析 → 选清晰度 → 下载 → 取回文件
   ▼
FastAPI 单进程（app/main.py，无数据库）
   ├── 静态托管 static/（html=True）
   ├── /api/*  业务接口
   ├── 内存状态：tasks / quota / stats
   └── 清理线程：每 300s 删除超过 TTL(1h) 的文件与任务
   ▼
下载引擎路由（app/downloader.py）
   ├── 抖音域名 ──► app/douyin.py 专用模块（requests + 游客 ttwid + ffmpeg）
   └── 其他平台 ──► yt-dlp CLI 子进程（tools/yt-dlp.exe）+ tools/ffmpeg
   ▼
downloads/ 临时文件（task_id.ext，1h 自动清理）
```

选型理由：
- **FastAPI**：代码量最少，一个进程同时提供页面与接口；本机已有 Python
- **封装 yt-dlp CLI 而非改源码 / 用 Python API**：官方 README 明确建议外部程序用 `-J`/`--print`/`--progress-template` 等稳定接口，不要解析易变 stdout；CLI 封装零改动、升级无忧
- **Windows 用独立 yt-dlp.exe**：自带 Python，绕开最新版对 Python 3.11+ 的要求
- **无数据库**：任务/额度/统计内存化，文件落临时目录定时清理，满足轻量诉求

## 2. API 设计

基础路径 `/api`，JSON 交互；错误统一 `{"detail": "友好中文提示"}`。

| 方法 | 路径 | 请求 | 响应 | 说明 |
|---|---|---|---|---|
| POST | `/api/parse` | `{url}` | video 或 playlist（见下） | 解析；400 链接/解析错误 |
| POST | `/api/download` | `{url, choice="best", title?, subtitle?}` | `{task_id}` | 建下载任务；429 额度用完；400 参数错 |
| GET | `/api/tasks/{id}` | — | `{id,status,percent,speed,title,error}` | 轮询进度；status∈queued/downloading/done/error |
| GET | `/api/files/{id}` | — | 文件流（attachment） | 取回成品；文件名=标题+扩展名；404 过期 |
| GET | `/api/quota` | — | `{remaining,limit}` | 当前 IP 今日剩余免费次数 |
| GET | `/api/stats` | — | `{downloads}` | 今日全站下载数（信任条展示） |

`/api/parse` 返回结构：
- 单视频：`{type:"video", engine?, video_id?, title, thumbnail, duration, uploader, webpage_url, choices:[{id,label,height,approx_size?}], subtitles:[lang]}`
  - `choices.id`：分辨率数字（如 `"1080"`）、`"audio"`、`"best"`
- 合集：`{type:"playlist", title, entries:[{title,url,duration}], total, truncated}`（entries 截断前 50）

`/api/download` 的 `choice` 与引擎映射：
- 抖音：仅接受 `best`（无水印 MP4）/ `audio`（MP3），其余归一为 `best`
- 其他：`audio`→抽流 MP3；`best`→最佳；数字→限高清晰度

## 3. 下载策略

### 3.1 路由
`downloader.parse/start_download` 先判 `douyin.is_douyin(url)`（含 douyin.com / iesdouyin.com）→ 走抖音模块；否则走 yt-dlp。

### 3.2 通用平台（yt-dlp）
- 解析：`-J --flat-playlist --no-warnings -- <url>`；playlist 取 entries 前 50，空合集报错
- 清晰度选择子（`_selector`）：
  - `audio` → `ba/b` + `-x --audio-format mp3`
  - `best` → `bv*+ba/b`
  - 数字 h → `bv*[height<=h]+ba/b[height<=h]/b`
- 兼容与封装：`-S vcodec:h264`（优先 H.264）、`--merge-output-format mp4`
- 进度：`--progress-template "download:@PROG@%(progress.downloaded_bytes)s,%(progress.total_bytes)s,%(progress.total_bytes_estimate)s,%(progress.speed)s"` + `--newline`
  - **关键坑**：`--print` 隐含 quiet 会吞掉进度输出，必须加 `--no-quiet`
- 成品路径：`--print after_move:filepath`；只认以 `downloads/` 开头的行作为路径
- 保护：`--max-filesize`（默认 500M）、`--windows-filenames`、`--trim-filenames 80`、`--no-playlist`
- 字幕：`subtitle` 经正则校验后 `--write-subs --sub-langs`

### 3.3 抖音（专用免登录模块）
1. **游客身份**：POST `ttwid.bytedance.com/ttwid/union/register/` 取 `ttwid`（缓存 6h），注入 `.douyin.com/.iesdouyin.com/.snssdk.com` 三个域——纯服务端生成，不碰用户登录态
2. **取 video_id**：短链先跟随重定向；从 `modal_id/item_ids/group_id/aweme_id` 或 `/video/ /note/` 路径正则提取
3. **取元数据**：GET `https://www.iesdouyin.com/share/video/{id}/`（移动 UA）；遇 WAF 挑战页用 SHA256 工作量证明求解 cookie 后重试； brace-matching 解析 `window._ROUTER_DATA` → `loaderData.*.videoInfoRes.item_list[0]`
   - 注：旧 `web/api/v2/aweme/iteminfo/` 主接口已失效（返回 0 字节），故直接走分享页
4. **无水印地址**：`video.play_addr.url_list[0].replace("playwm","play")`，流式下载为 MP4
5. **仅音频**：分享页 `music.play_url` 为空，故先下无水印视频再 `ffmpeg -vn -acodec libmp3lame -q:a 2` 抽 MP3，删中间视频
6. 进度：按 Content-Length 计算百分比（音频模式视频段 0–90%、转换 95%、完成 100%）

来源与许可：adapted from [rathodpratham-dev/douyin_video_downloader](https://github.com/rathodpratham-dev/douyin_video_downloader)（MIT），增强游客 ttwid 与 ffmpeg 抽音频。

### 3.4 并发 / 配额 / 清理
- 并发：`threading.Semaphore(3)`，超出排队（status=queued）
- 配额：`quota[ip]={date,count}`，跨天重置；`FREE_DAILY_LIMIT` 默认 5；下载发起即计数
- 清理：守护线程每 300s 删 `created` 超 1h 的任务及其文件，并扫目录删超龄文件
- 统计：`stats={date,downloads}` 供信任条

### 3.5 安全边界
- URL：`urlparse` 协议白名单 http/https + 必须有 netloc
- 子进程：列表参数、不用 shell；URL 前置 `--` 防选项注入
- 参数：`choice` 数字正则 / 抖音枚举；`subtitle` 正则 `[\w-]{1,20}`
- 前端：标题等一律 `esc()` 转义防 XSS；封面 `referrerpolicy="no-referrer"`
- 文件取回：仅允许 done 任务的 filepath，文件名过滤非法字符

## 4. 目录结构

```
free-video-downloader/
├── app/
│   ├── __init__.py
│   ├── main.py          # FastAPI 入口 + 路由 + 静态托管 + 清理线程启动
│   ├── downloader.py    # yt-dlp 封装 / 路由 / 配额 / 并发 / 清理
│   └── douyin.py        # 抖音免登录解析下载模块
├── static/
│   ├── index.html       # 页面结构（hero/结果/功能/价格/FAQ）
│   ├── style.css        # 白底亮蓝轻 SaaS 风 + 响应式
│   └── app.js           # 解析/下载/进度/批量/合集/额度交互
├── docs/
│   ├── 需求分析.md
│   └── 方案设计.md
├── tools/               # yt-dlp.exe / ffmpeg.exe / ffprobe.exe（gitignore）
├── downloads/           # 临时成品文件（gitignore，1h 清理）
├── requirements.txt     # fastapi / uvicorn / requests
├── start.bat            # Windows 一键启动
├── .gitignore
└── README.md
```

## 5. 前端设计要点

- 配色取自参考站实测：主蓝 `#1777FF`、标题 `#0F172A`(900)、激活标签 `#EFF6FF/#2563EB`、白底
- 核心交互：中央大胶囊输入框 + 内嵌蓝色「解析视频」；信任条（服务正常/平台数/今日下载/剩余额度）
- 结果卡：封面 + 标题 + 清晰度 chips + 进度条 + 「保存到本地」；合集卡带勾选/全选/清晰度下拉
- 付费引导：三档价格卡（月度推荐蓝色放大 + 「最受欢迎」徽章），超额 toast 带「看看会员→」
- 响应式：768px 折叠导航/卡片纵排/价格单列；480px 功能单列
